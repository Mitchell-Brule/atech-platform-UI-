// Atech 14-Port Microcontroller Firmware
#include <atech.h>

AtechController atech(BOARD_14P);
VL53L5CX_Distance dist_sensor(PORT_1);
I2S_Speaker audio_out(PORT_2);
NeoPixel_Matrix pixels(PORT_3);

void setup() {
  atech.begin(115200);
  dist_sensor.setRangeMode(DISTANCE_8x8);
  audio_out.setVolume(85);
  pixels.setBrightness(120);
}

void loop() {
  int distance_mm = dist_sensor.readZone(4, 4);
  if (distance_mm < 350) {
    audio_out.playTone(map(distance_mm, 30, 350, 880, 220), 40);
  } else {
    audio_out.stop();
  }
}

How It Works — The 6-Step Hardware Pipeline

END-TO-END WORKFLOW
01
Describe your idea

Tell it what you want to build in plain English. Describe sensors, inputs, displays, and desired device behavior.

02
AI generates your build

It selects the modules, auto-assigns the 14-ports, generates parametric 3D CAD enclosure, and writes working C++ firmware.

03
Buy your modules

Order an Early Adopter starter kit or customize standalone modular sensors, screens, buttons, and actuators.

04
Assemble your modules

Snap modules into labeled ports using universal 6-pin ribbon harnesses with zero soldering required.

05
Plug in

Connect USB-C from your 14-Port motherboard to your computer and the browser handles flashing automatically via WebUSB.

06
Upload & run

Hit run and watch your idea come to life in seconds. Debug live telemetry or link directly into your own CLI agent.
